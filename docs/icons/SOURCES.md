Notes:

- The PNG variant is used instead of `opentelemetry-icon-color.svg` from the same directory because d2 v0.9.0 PNG export rejects that SVG (`d2svgimport: unsupported stylesheet selector`).
- Temporal server has no icon: the temporalio/temporal repository does not ship a logo file (its README references a GitHub avatar image), so per the icon rules the node is labelled in text only.
